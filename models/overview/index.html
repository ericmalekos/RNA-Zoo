    Model Overview¶

    RNA-Zoo runs 23 models in six tracks: 13 task programs and 10 embedding models. Each model runs in its own container image, with its weights inside.

    All models at a glance¶

    Model Track Task Input Output Device
    RiboNN Translation Translation efficiency in 78 human cell types TSV of 5' UTR, CDS and 3' UTR sequences TSV of TE per cell type CPU or GPU
    Riboformer Translation Codon-level ribosome density in a target condition Directory of WIG, FASTA and GFF3 files Density per codon window CPU or GPU
    RiboTIE Translation Translated ORFs from ribosome profiling Directory of FASTA, GTF and BAM files, plus a YAML config ORFs as CSV and GTF per sample CPU or GPU
    TranslationAI Translation Translation start and stop sites, and ORFs FASTA of mRNAs Text files of sites and ORFs CPU
    Saluki Translation mRNA half-life score FASTA (UTRs lowercase, CDS uppercase), optional exon lengths TSV and NumPy array CPU or GPU
    CodonTransformer Translation Codon optimization for 164 organisms FASTA of proteins FASTA of DNA coding sequences CPU or GPU
    RNA-FM Foundation RNA embeddings, 640-d FASTA NumPy (N x 640) CPU or GPU
    RiNALMo Foundation RNA embeddings, 1280-d FASTA NumPy (N x 1280) CPU or GPU
    ERNIE-RNA Foundation Structure-aware RNA embeddings, 768-d FASTA NumPy (N x 768) CPU or GPU
    Orthrus Foundation Mature mRNA embeddings, 512-d (256-d for two of the seven checkpoints) FASTA of mature mRNAs NumPy (N x D) GPU only
    HydraRNA Foundation Full-length RNA embeddings, 1024-d FASTA NumPy (N x 1024) GPU only

    Pangolin Splicing Variant effects on splice-site strength, from models of four tissues VCF or CSV, reference FASTA, gffutils database VCF or CSV with scores CPU or GPU

    By track¶

    Translation¶

    RiboNN, TranslationAI, Saluki and CodonTransformer need only sequences. Riboformer and RiboTIE also need ribosome profiling data: Riboformer predicts the density in a target condition from a reference dataset, and RiboTIE fine-tunes on each sample's reads before it calls ORFs.

    RNA foundation models¶

    The nine foundation models and SpliceBERT (splicing track) return embeddings: one vector per sequence in sequence_embeddings.npy, the names in labels.txt, and one vector per token with --<model>_per_token. They differ in size, pretraining data and input limit:

    Model Parameters Width Pretraining data Max input
    RNA-FM 99.5M 640 23M non-coding RNAs (RNAcentral) 1,022 nt
    RiNALMo 650.9M 1280 36M non-coding RNAs (RNAcentral and other databases) No cap; memory-bound
    ERNIE-RNA 86.3M 768 20.4M non-coding RNAs (RNAcentral) 1,022 nt
    Orthrus 10.2M (default checkpoint) 512 (256 for two checkpoints) Splice isoforms of ten metazoans and orthologs from over 400 mammals, by contrastive learning No cap
    HydraRNA 84.2M 1024 28M non-coding RNAs and mRNAs No cap; 10,240-nt chunks, averaged
    RNAErnie 86.6M 768 About 31M RNAcentral sequences (a later PyTorch model by the authors, not the paper's) 2,046 nt
    PlantRNA-FM 33.8M 480 Transcripts of 1,124 plant species (about 25M sequences) 1,024 nt
    CaLM 85.7M 768 9M coding sequences (European Nucleotide Archive) 1,024 codons
    mRNABERT 113.4M 768 About 18M mRNAs 1,022 tokens (UTR nucleotides and CDS codons)
    SpliceBERT 19.4M 512 Over 2M primary RNAs from 72 vertebrates 1,024 nt

    Inputs over the limit are truncated with a warning. The sequence embedding is the mean over positions, without the start and end tokens; ERNIE-RNA instead returns its CLS token.

    RNA structure¶

    RhoFold and DRfold2 predict 3D structure from a single sequence. RhoFold takes up to 1,022 nt and runs on CPU or GPU; DRfold2 has no length cap but needs a GPU. SPOT-RNA predicts secondary structure, including pseudoknots and non-canonical pairs.

    Splicing¶

    SpliceAI and Pangolin score variants against a reference genome and a gene annotation. SpliceBERT only returns embeddings.

    Fine-tuning¶

    The nine foundation models can train a linear, MLP or XGBoost head on their frozen embeddings and your labels; see the Fine Tuning guide. SpliceBERT has no fine-tuning parameters. RiboTIE fine-tunes its pretrained models on each sample's reads in every run. RiboNN and UTR-LM have their own fine-tuning modules, but both currently fail and are not tested; a fix is planned for a later release.
